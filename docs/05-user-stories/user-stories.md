# User Stories

User stories describe the system requirements from the perspective of the users who will interact with the system.

## User Stories

| Story ID | User Story |
|---|---|
| **US-01** | As a student, faculty member, or OSA staff member, I want to register and log in to the system, so that I can access the functions available to my role. |
| **US-02** | As a faculty member, I want to record student attendance as present, absent, or late with remarks, so that student attendance can be properly monitored. |
| **US-03** | As a faculty member, I want the system to identify students who reach the required absence percentage, so that I can determine which students need to be dropped. |
| **US-04** | As a faculty member, I want to drop students who reach the required absence percentage, so that their dropping status is properly recorded. |
| **US-05** | As a student, I want to submit a re-admission request after being dropped, so that I can process my return to the academic program. |
| **US-06** | As an OSA staff member, I want to generate drop and re-admission data, so that I can organize and monitor student academic transitions. |
| **US-07** | As an OSA staff member or faculty member, I want to archive past school year records, so that I can keep current records organized while preserving previous academic records. |
