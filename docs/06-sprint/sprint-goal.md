# Sprint Goal

## Sprint 1

### Sprint Goal

> **Establish the foundation of the system by setting up the collaborative development environment and implementing secure role-based authentication and faculty attendance recording.**

## Sprint Focus

Sprint 1 focuses on establishing the core features required before the team can proceed to the automated dropping and re-admission workflows.

The sprint focuses on:

- Student authentication
- Faculty authentication
- OSA authentication
- Role-based dashboard routing
- Faculty attendance recording
- Attendance remarks
- Initial database setup
- Collaborative Git repository setup

## Sprint Success

The Sprint Goal is achieved when:

1. Students can securely log in and access their appropriate dashboard.
2. Faculty members can securely log in and access their assigned class rosters.
3. OSA staff can securely log in and access the centralized OSA dashboard.
4. Faculty members can record student attendance.
5. Faculty members can add optional attendance remarks.
6. Attendance records can be saved correctly.
7. The initial database structure supports the implemented features.
8. The completed work is integrated into the shared development repository.
